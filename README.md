-CLI TASK MANAGER(in GOLANG)

-Every task in the program contains:
->taskId(string)
->taskName(string)
->status(bool)
->createdAt(string)

-Every task will get saved in the taks.json file

-For now every task will be given a task id based on a counter variable and it will get incremented based on every task
-Even if some task get deleted in between we still increament the counter and gave task on that basis
